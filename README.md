# Daymark Teacher — Practice Demo

This repository contains **only** the Daymark Teacher browser demonstration, with fictional pupils and no personal pupil records.

## Try the demo

Once GitHub Pages is enabled (Settings → Pages → Deploy from a branch → main → /(root)), open:

https://jamierussell197814-creator.github.io/daymark-demo/

## What is inside

- Day-to-day teacher checklist
- Year 3 Mastering Number sample prompts
- A two-click interaction tracker using six fictional names
- Optional Outwoods rules and values recognition tags
- A daily reflection report
- A child-facing whiteboard preview

The demo runs in-browser without a login or installation. It does not use a database, localStorage, cookies or server uploads for interaction records. Entries exist only in temporary page memory and reset when the tab reloads.

**Never enter real pupil records in this public demo.** It is an unapproved software prototype, not an authorised school record-keeping system.

Desktop application source is kept separately in a private repository.
